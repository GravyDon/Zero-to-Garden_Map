# Obsidian organization project notes
### Item #1: Link Contextualization x Extended graph plugin
It is possible to create customisable link relations in the extended graph plugin. This would allow for the creation of a link hierarchy that could be used to more effectively navigate between files based on contextual research needs rather than having to guess the relevance of one file to another or explicitly know by being intimately familiar with the vault. This is a similar effect to the excalibrain ontology, but, instead of the ontology determining link direction, it will determine the color. I think color coding will be a superior way to link many files in a vertical and horizontal hierarchy without having to reduce to a local view. Even in a local view, semantics are leveraged by color coding: an easier semantic trigger than cardinal orientation in the horizontal regime, but perhaps worse in the vertical regime. Excalibrain has effectively been replaced with a tool that actually suits my needs though. I'd much prefer going forward with this methodology than trying to hamfist excalibrain and its complicated, clunky UI into the mix now.

I'm writing out some link types that I want to integrate, but if the number is too great, it might be best to omit some for performance reasons. 

#### Vertical link types

	Vertical link types imply a hierarchy that distinguishes the semantic order in which notes should be processed. Ideally, integration of vertical links should facilitate flow between notes that is linear.

- **Consolidation**: a general relation that groups many files together in a summary or emergent structure. The emergent structure might be considered in a higher or lower layer of semantic structure depending on the content (i.e. a higher layer would be a summary, meta-study, or any note that is both capturing the bulk of the relevant notes' content and building on it. a lower layer would be a specific study related to all consolidated notes, but is not making any emergent commentary from bulk note content. Something in this category could be focusing on a specific issue or topic of interest whose connection to other files could be advantageous to increasing overall understanding of consolidated notes in introducing new perspective(s))
- **Prerequisite**: a general relation that is action biased. this note relation makes an order of execution between actions. The advantage of this in terms of creating a path towards industrial autonomy cannot be understated as one technological capability necessarily leads to another and so on. Budgeting is another consideration that would greatly benefit from this semantic inclusion.
### Horizontal link types

	Horizontal link types are meant to provide topical semantic connections between notes. It's meant to provide a non-linear connection between notes that can be visualized. However, this by no means is meant to replace tags. the connections between notes should be 1:1 and not something that can be done via a tag node.

- **Antagonistic and symbiotic**: relations between plants and other living organisms. Self-explanatory (do they play nice :D).
