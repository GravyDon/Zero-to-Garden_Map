Templates are a great tool! They can be used to initialize a file ready to take notes in. Integrating organization with the usage of templates, especially with repetitive theming between notes. 

## Using templates
Make sure that you have a new file selected before doing this. Doing this in a document with content in it can insert unwanted content. You can press ctrl+z if this happens.
- press ctrl+p
- With the command tab pulled up, type "insert template"
- Another dropdown will appear -> choose your template from the dropdown
