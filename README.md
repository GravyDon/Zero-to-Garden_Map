## 🎯 Motivation
This repository serves as a basis of knowledge on gardening. The entire collection of knowledge aims to connect each individual recipient of this knowledge to be able
to grow food, medicine, and natural resources in whatever way they can manage. In this initiative, equitable access to successful techniques for cultivation is essential, 
no matter if these means might not necessarily be modern. All ways towards peace and happiness are welcome!

Being organized using [Obsidian](https://obsidian.md/), which is available on all platforms, it is highly preferred that you download and use this program
to contribute to the notes. A specific document on how notes are organized will be introduced at a later date. 

Due to the size of this repository, the preferred method of usage resides in the functionality of Obsidian to organize, navigate, and proliferate notes in
an integrated fashion, such that all notes are put into context with larger whole of information. The vault is updated on a daily basis on the main branch (main contributor branch). If you would like to contribute, please do so on the general branch or 
ask for your own branch. Feel free to duplicate the repository under your own administration as well. 

## ✨ Features

- ✅ Ongoing repository of gardening related information (managed by 1 person)
- 🎉 Detailed plant entries that cover the bases of 
  germination, seed-starting, sowing, transplanting, soil conditions, physical description, uses, and recipes (where applicable
- 🚀 Detailed action plans; spring into action!
- 💡 Visualizations of relationships between notes using graphview and excalibrain plugins
- 📍 Index to navigate concepts relevant to gardening from techniques, plant types, roles, and functions, and more!
- 🕺 Connect with cool gardening pals on cool gardening topics!! We are here to learn and grow together!!

## 🚀 Getting Started

Firstly, download the [obsidian client](https://obsidian.md/download) to view your notes in a tolerable format

To install and initialize this repository, there are two approaches:

##### First method (tested on a Windows 10):
1. Press the green "Code" button to download a zip file
2. Extract folder into the desired directory; if you don't have one, simply extract the zip file

### Second method

Input the following commands into your terminal:
```bash
cd ~
git clone https://github.com/GravyDon/GardeningBackup/tree/GeneralSharing
```
This will copy the repository into your home directory (if you don't know what this is, use the first method)

### Finishing installation
-  Open your Obsidian client and select "Open folder as vault"
-   Navigate to the extracted folder and select.
-   Install all dependencies 

  Congrats! Now you have the notes in your hands 🙌 GOOD LUCK!!

## 🎮 Usage
  More details on navigating the vault can be found within the vault itself. But do not fear! The .obsidian/workspace.json file will initialize a view of the vault that will help with navigation
  useful hotkeys:
  ctrl+shift+t : re-open closed tab
  ctrl+z : undo action
  ctrl+p : open command pallette 
  ctrl+q : open workspaces tab; save and load different sessions
  ctrl+g : open graph view

  If you like how the vault is organized, please maintain the following practices to take advantage of the organization on your new files:
1. Initialize files with templates (can be found in the command panel (ctrl+p) under the "insert template" command
2. Use [tags](https://help.obsidian.md/tags) and [links](https://help.obsidian.md/link-notes)!! 
3. Create excalibrain snapshots for complete plant notes (I can explain this for those interested)

  [For looking into how to use Obsidian in general, this link is the best resource](https://help.obsidian.md/)

  List of community plugins required for obsidian:
  - Advanced tables
  - Advanced URI
  - Buttons
  - Code emitter
  - Commander
  - Dataview
  - Excalibrain
  - Excalidraw
  - Git
  - Heatmap Calendar
  - Iconoir Icons
  - MetaEdit
  - QuickAdd
  - Tab Panels
  - Tag Page
  - Tag Wrangler
