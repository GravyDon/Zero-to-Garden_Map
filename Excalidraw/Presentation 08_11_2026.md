# Biodigester
This machine will readily supply the needed fertilizers, manure, and a value added product of natural gas for a piece of land. The inputs can be obtained either from the land itself or from an external source, thus charging the land with more nutrients and ions.

Pros: 
- Sustainable source of fertilizer obtained from harnessing decomposition
- Can be easily scaled using multiple modules
- Provides value added product of methane, which if scaled with operations, can create an energy independent land dev project. 
- Cheap
Challenges: 
- Manure needs to be manually extracted
- Gas filtration on site
- Sheltering on site
- Sourcing material for continual operation 
- Sourcing inoculation material
- Extraction of manure unsolved (current model and methods only account for fertilizer and gas extraction)
# Eco Machines
John Todd's work in the 80s demonstrated the potential of orchestrating ecologies to perform tasks of purification of the water, soil, and reconstituting the environment with life. Being able to replicate these machines would be carrying forward his work and connecting us to his legacy. This both allows for development upon an already rich methodology and access to already proven, grant-worthy research methods

Pros: 
- Very few moving parts
- Uses ecologies -> Establishing ecosystem for further use and for restoring marshland and wetland ecosystems
- Water purification
- Established context for obtaining grant money
Challenges: 
- Requires large or numerous, above ground water containers. 
- Sourcing microorganisms and plants to occupy the eco-machine modules
- Finding land that can properly demonstrate/test the restorative power of these machines
- Potentially expensive
# Biochar Reactor
Biochar has many uses dependent upon its manufacturing parameters. From water purification, to soil amendments, to fuel, this installation will provide key resources for running the land dev project. Most importantly, it is still a largely experimental, not widely adopted approach which can bolster the available methods that the community can access if only they had a model to inspire them. Feedstock can be sourced from local plants or external waste; feedstock will effect properties of the biochar. 

Pros:
- Can produce valuable material with value added products (syngas, bio-oil, charcoal)
- Flexible assembly options (either very easy with limited parameter control to complex with precise parameter control)
- Cheap
Challenges: 
- Can produce harmful byproducts 
- Resource intensive burn process (dependent on combustion method, efficiency, and feedstock capacity per burn)
