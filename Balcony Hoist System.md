Engagement Meter
#IDEA Making an engagement meter that will indicate how many times one visits the note, last time the note was edited (shouldn't be abused), and the number of connections that the note has to other things

### Context

In organizing Robiii's house to be fit for both our means, It's imperative to have the transportation between the carport and the rest of the house to be streamlined. If that isn't the case, work is going to be a mess; transporting things up stairs, through rooms, through multiple doors and past the altar ;\_;
That would be very stress inducing...

This is a way to transport things vertically from the carport to the balcony using basic physical principles
